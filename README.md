# CAREECON+ パートナー募集LP（サーバーアップロード用）

このフォルダの中身をそのままサーバーの公開ディレクトリ（例：partner.careecon.jp のドキュメントルート）にアップロードしてください。

## 構成
- index.html … ページ本体（文言・レイアウトはここを編集）
- support.js … ページ表示用ランタイム（編集不要）
- image-slot.js … 画像枠コンポーネント（編集不要）
- ds/ … CAREECON+ デザインシステム（ボタン・フォーム等の部品と色・文字の定義）
- assets/ … 画像
  - careeconplus_logo.png … ロゴ
  - logo-marquee.webp … 導入企業ロゴ（ループ表示）
  - badge-17-years.png … 17周年バッジ
  - slots/ … 各セクションのアイコン・写真

## 画像の差し替え
assets/ 内の同名ファイルを上書きすれば反映されます（ファイル名・拡張子は変えないでください）。

## 注意
- フォントは Google Fonts から読み込むため、インターネット接続が必要です。
- フォームはまだ送信先が未設定です（HubSpot 等の連携が必要）。
- ローカルで index.html をダブルクリックすると一部が表示されない場合があります。サーバー上（または簡易サーバー）で確認してください。
